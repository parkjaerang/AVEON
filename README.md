# AVEON COMPANY

에비온컴퍼니 공식 기업 소개 홈페이지입니다. 한국 피부과·뷰티 기업의 중국 시장 진출을 위한 마케팅 서비스를 소개합니다.

HOME에는 메인 비주얼, 서비스 요약(2×2), 플랫폼 소개(샤오홍슈·더우인·위챗), 경쟁력 및 상담 CTA가 포함되어 있습니다.

## 기술 스택

- Vue 3 + TypeScript
- Vite
- Vue Router
- Composition API (`<script setup lang="ts">`)
- Lucide Vue Next

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 빌드

```bash
npm run build
npm run preview
```
